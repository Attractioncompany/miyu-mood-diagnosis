# 미유 예시 연예인 공식 영문명 근거

## 확인 원칙

- 2026-08-05에 소속사·그룹·아티스트·공인 스포츠 단체·영화진흥위원회(KOFIC)의 공식 페이지를 확인했다.
- 그룹 소속은 `그룹명 · 개인명`, 배우는 `이름 · ACTOR`, 솔로 가수는 `이름 · SOLO ARTIST`로 표시한다.
- 공식 페이지가 이름을 모두 대문자로 디자인한 경우에도 철자와 띄어쓰기는 유지하되, 개인 이름은 읽기 쉬운 고유명사 표기로 정규화했다. 그룹의 공식 대소문자와 `Rosé`, `YooA`, `Kim YooYeon` 같은 고유 철자는 유지했다.
- 아래 적용 이름을 합치면 원본 v16의 고유 고객 노출 라벨 97개를 모두 포함한다.

## 빌드 적용 규칙

`src/celebrity-names.js`는 원본의 한글 라벨을 정확한 키로 관리한다. v17 생성 중 `.person-name`과 `.cat-representative`의 이름을 치환하며, 사전에 없는 이름을 발견하면 결과 파일을 쓰기 전에 빌드를 중단한다. 따라서 새 예시 인물을 원본에 추가할 때는 이 문서의 공식 근거와 이름 사전을 함께 갱신해야 한다.
