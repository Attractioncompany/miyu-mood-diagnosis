# 미유 전체 해설 번역·남성 체크리스트 이미지 설계

- 작성일: 2026-07-30
- 대상: `미유_무드진단_12type_v17.html`
- 상태: 사용자 승인 설계
- 선행 설계: `2026-07-30-miyu-bilingual-gender-explanation-design.md`

## 1. 해결할 고객 불편

현재 최종 해설은 상단의 짧은 설명만 한국어와 고객 언어로 제공하고, 대표 특징·정의·키워드·상세 특징표는 한국어만 보여준다. 외국인 고객은 해설의 핵심 근거를 직접 읽지 못하고 컨설턴트의 구두 설명에 의존한다.

남성 고객은 진단 문항에서 여성 얼굴 예시를 보게 된다. 특히 얼굴형과 이목구비의 차이를 이미지로 비교하는 문항에서는 자신의 얼굴과 예시를 연결하기 어렵다. 이미지 확대 기능은 태블릿 진단 흐름에 불필요한 조작을 추가한다.

이번 변경은 다음 문제를 해결한다.

1. 최종 해설의 모든 고객용 내용을 한국어와 고객 언어로 함께 제공한다.
2. 성별에 맞는 체크리스트 이미지를 자동으로 표시한다.
3. 번역과 이미지 누락을 배포 전에 자동으로 발견한다.
4. 예시 연예인 이름을 언어마다 다르게 옮기지 않고 공식 영문 표기로 통일한다.

## 2. 확정된 변경 범위

### 포함

- 최종 해설의 모든 고객 노출 내용 번역
- 한국어와 선택 언어 동시 표시
- `검토 메모` 제목과 내용 제거
- 여성 예시 연예인의 그룹명·개인명 공식 영문 표기
- 남성 체크리스트 AI 이미지 34개 제작
- 성별에 따른 체크리스트 이미지 자동 전환
- 체크리스트 이미지 확대 버튼·확대창·관련 동작 제거
- 성별과 무관한 문항 표현으로 두 문구 수정
- 번역·이미지·영문 이름 누락을 막는 자동검사
- 태블릿 세로·가로 및 출력 화면 검증
- 독립 실행 가능한 단일 v17 HTML 재생성

### 제외

- 진단 문항과 ABCD 답변 전체의 다국어 번역
- 진행표·점수표·타입 선택 화면·메뉴·출력 버튼의 번역
- ABCD 점수 기준과 12타입 매핑 변경
- 기존 여성 체크리스트 이미지 교체
- 신규 남성 연예인 목록 또는 사진 추가
- 브라우저 실시간 자동번역
- 서버 저장, 로그인, 고객 데이터베이스
- 사용자 확인 전 공개 링크 배포

보관용 원본인 v16 HTML은 수정하지 않는다. `검토 메모` 제거와 신규 기능은 생성되는 v17에 적용한다.

## 3. 사용자 흐름

1. 고객명·컨설턴트명·해설 언어·성별·진단일을 입력한다.
2. 선택한 성별에 맞는 체크리스트 이미지로 10문항을 진행한다.
3. ABCD 점수표와 12타입을 확인한다.
4. 컨설턴트가 최종 타입을 선택한다.
5. 최종 해설의 모든 고객용 내용을 한국어와 선택 언어로 함께 본다.

기존 규칙은 유지한다.

- 문항마다 최대 2개 선택
- 이전 문항으로 이동 가능
- PDF 순서대로 12타입 표시
- 점수와 관계없이 컨설턴트가 최종 타입 선택 가능
- 여성 B그룹은 `Feminine · 페미닌`, 남성 B그룹은 `Boyish · 보이시`

## 4. 체크리스트 성별 이미지

### 이미지 전환

- 여성 선택: 현재 PDF에서 추출한 이미지 34개 사용
- 남성 선택: 신규 AI 남성 이미지 34개 사용
- 이미지가 없는 9·10번 문항: 현재처럼 텍스트만 표시
- 진단 중 뒤로가기를 사용해도 최초 선택한 성별 이미지 유지
- 새 진단에서 성별을 다시 선택하면 해당 이미지 세트로 변경
- 성별은 이미지에만 영향을 주며 문항 순서와 ABCD 점수 기준은 바꾸지 않음

이미지 경로는 여성·남성을 명시적으로 분리한다. 문항 데이터는 같은 답변 코드에 `female`과 `male` 이미지 목록을 각각 연결한다. 성별에 맞지 않는 이미지로 자동 대체하지 않는다.

### 문항 문구 수정

남성 이미지와도 맞도록 다음 두 문구를 성별과 무관한 표현으로 변경한다.

| 문항 | 기존 | 변경 |
|---|---|---|
| 3번 이마 B | 예쁜 이마 | 곡선이 자연스럽고 균형 잡힌 이마 |
| 7번 코 B | 여성스러운 코 (코가 강하게 부각되지 않음) | 부드럽고 강하게 부각되지 않는 코 |

답변 코드와 점수는 변경하지 않는다.

### 이미지 확대 제거

체크리스트 카드에서는 이미지를 누르지 않고 바로 비교한다.

- 확대 버튼 제거
- `확대` 표시 제거
- 체크리스트 전용 확대창 제거
- 체크리스트 전용 이미지 열기·닫기 이벤트 제거
- 이미지 선택 버튼과 답변 선택 동작은 기존처럼 분리

이번 제거는 체크리스트에만 적용한다. 기존 해설의 출력이나 다른 이미지 기능을 임의로 제거하지 않는다.

## 5. 남성 AI 이미지 제작 기준

남성 이미지는 34장을 서로 다른 조건으로 생성하지 않는다. 문항별로 비교 세트를 만들어 해당 문항 안에서 얼굴 특징 이외의 차이를 최소화한다.

### 공통 기준

- 동아시아 성인 남성
- 중립적인 표정
- 정면 또는 문항에 필요한 고정 각도
- 같은 문항 안에서 연령대·조명·배경·피부 표현·카메라 거리 통일
- 안경·수염·액세서리·강한 메이크업·과도한 헤어 스타일링 제외
- 특징을 가리는 앞머리 제외
- 자연스러운 피부 질감
- 진단 특징을 과장한 캐릭터 그림이 아닌 현실적인 참고 이미지
- 태블릿 카드에서 얼굴 또는 해당 부위가 잘리지 않는 구성

### 문항별 구도

| 문항 | 이미지 수 | 중심 구도 |
|---|---:|---|
| 1. 얼굴형 | 5 | 얼굴 전체 정면 |
| 2. 턱선 | 4 | 얼굴 전체와 하관 |
| 3. 이마 | 4 | 이마·헤어라인이 드러난 정면 또는 약한 측면 |
| 4. 눈썹 | 4 | 양쪽 눈썹과 눈 주변 |
| 5. 눈 | 4 | 양쪽 눈과 눈꼬리 |
| 6. 광대 | 5 | 정면과 필요한 경우 약한 측면 |
| 7. 코 | 4 | 코 형태가 보이는 정면 또는 약한 측면 |
| 8. 입 | 4 | 입과 인중 주변 |
| 합계 | 34 |  |

각 이미지는 기존 A·B·C·D 답변의 형태 기준과 일치해야 한다. C답변에 두 이미지가 있는 1번과 6번은 두 형태 또는 두 각도를 모두 보존한다.

AI가 생성한 해부학적 특징은 자동으로 정확하다고 간주하지 않는다. 초안 이미지로 구현한 뒤 문항 문구와 실제 시각적 특징이 일치하는지 사람 검수를 거친다. 불명확한 이미지는 공개 배포 전에 재생성한다.

## 6. 전체 해설 번역 범위

최종 타입 해설에서 고객이 볼 수 있는 모든 설명을 번역한다.

- 타입·그룹 제목과 짧은 소개
- 대표적인 특징 요약
- 정의
- 무드 키워드
- 얼굴형·두상·헤어라인·이마·눈썹·눈·코·입·귀·턱 등 상세 특징표
- 전체 인상
- 장점
- 헤어
- 메이크업 또는 그루밍
- 패션
- 피하면 좋은 방향
- 고객에게 보이는 기타 해설 문장과 섹션 제목

지원 언어는 다음 세 가지다.

- 일본어
- 중국어 간체(중국)
- 중국어 번체(홍콩·대만)

진단 문항, 진행표, ABCD 점수표, 타입 선택 화면, 메뉴, 뒤로가기, 출력 버튼은 컨설턴트용이므로 한국어를 유지한다. 고객명·컨설턴트명·진단일은 번역하지 않는다.

## 7. 병기 화면

해설을 한국어 페이지와 번역 페이지로 두 번 반복하지 않는다. 같은 의미 단위 안에서 한국어와 선택 언어를 묶는다.

### 일반 설명

- 세로 태블릿: 한국어 위, 선택 언어 아래
- 가로 태블릿: 폭이 충분한 카드에서는 한국어와 선택 언어를 좌우로 표시
- 두 언어를 탭이나 버튼으로 숨기지 않음

### 상세 특징표

태블릿 표가 가로로 너무 넓어지지 않도록 같은 셀 안에 두 언어를 위아래로 표시한다.

```text
진하고 깊은 쌍꺼풀의 큰 아몬드형 눈
深くはっきりした二重の大きなアーモンド形の目
```

카테고리 이름과 표 제목도 같은 방식으로 번역한다. 빈 항목을 나타내는 `—`는 그대로 사용한다.

### 출력

출력 화면에도 현재 화면과 같은 한국어·선택 언어 쌍을 포함한다. 인쇄 과정에서 한 언어가 숨겨지거나 표가 잘리지 않아야 한다.

## 8. 검토 메모 제거

`검토 메모`는 고객 해설이 아니므로 생성되는 v17에서 제목과 내용을 모두 제거한다.

- 화면에서 공간만 숨기는 방식으로 처리하지 않음
- 번역 데이터에 포함하지 않음
- 출력 결과에 포함하지 않음
- 단일 HTML 문자열에도 남기지 않음
- 보관용 v16은 변경하지 않음

## 9. 연예인 영문 표기

여성 해설의 기존 예시 연예인 사진은 유지하되 그룹명과 개인명은 선택 언어와 관계없이 공식 영문 표기를 사용한다.

표기 형식은 다음과 같다.

- 그룹 소속: `OFFICIAL GROUP NAME · Official Person Name`
- 배우: `Official Person Name · ACTOR`
- 솔로 가수: `Official Stage Name · SOLO ARTIST`
- 기타 직업: 공식 영문명 뒤에 검증된 영문 직업명 표기

임의 번역이나 중국어·일본어 음역을 만들지 않는다. 공식 표기가 여러 개면 소속사·공식 프로필·본인 공식 채널에서 사용하는 국제 표기를 우선한다. 영문 대소문자는 공식 표기를 따른다.

남성 해설에는 검증된 남성 연예인 목록이 없으므로 연예인 영역을 표시하지 않는다. 여성 연예인을 남성 해설의 대체 자료로 사용하지 않는다.

## 10. 중앙 콘텐츠 구조

현재의 분산된 해설 문구를 하나의 구조화된 콘텐츠 모듈에서 관리한다.

각 타입은 다음 내용을 가진다.

- 공통 얼굴 특징
- 성별별 전체 인상과 스타일 해설
- 섹션 제목
- 대표 특징 목록
- 정의
- 무드 키워드
- 상세 특징표
- 언어별 번역
- 여성 예시 연예인 영문 표기
- 해설 이미지 연결 정보

각 번역 항목은 한국어 원문과 `ja`, `zh-CN`, `zh-TW`를 같은 의미 단위로 묶는다. 화면 코드는 번역 문장을 직접 보관하지 않고 콘텐츠 모듈에서 불러온다.

추후 문구 검수 때는 이 콘텐츠 모듈만 수정한 뒤 단일 HTML을 다시 생성한다. 기존 v16 해설을 화면에서 직접 읽어 번역하는 방식이나 브라우저 실시간 자동번역은 사용하지 않는다.

## 11. 누락과 오류 처리

초안 생성 단계부터 누락을 조용히 허용하지 않는다.

- 지원 언어의 번역이 하나라도 빠지면 v17 생성 중단
- 남성 이미지 34개 중 하나라도 빠지면 v17 생성 중단
- 존재하지 않는 이미지 경로가 있으면 생성 중단
- 연예인 한글명이 고객 화면 데이터에 남으면 생성 중단
- `검토 메모` 문자열이 생성 결과에 남으면 생성 중단
- 체크리스트 확대 버튼 또는 관련 동작이 남으면 생성 중단

화면 실행 중 예상하지 못한 값이 들어오면 화면 전체를 깨뜨리지 않고 시작 화면으로 돌린다. 번역 누락을 한국어만 표시하거나 `번역 준비 중`으로 대신해 완성된 것처럼 보이게 하지 않는다.

## 12. 검증 기준

### 체크리스트

- 여성 선택 시 기존 여성 이미지 34개 표시
- 남성 선택 시 신규 남성 이미지 34개 표시
- 1·6번의 복수 이미지 답변 보존
- 9·10번은 텍스트만 표시
- 이미지 확대 버튼·확대창·관련 이벤트 없음
- 수정한 두 문항 문구 표시
- 성별과 관계없이 동일한 답변 코드와 점수 계산
- 이미지가 카드 안에서 잘리지 않음

### 전체 해설 번역

- 12타입 각각에서 세 지원 언어 검사
- 모든 고객용 섹션에 한국어와 선택 언어가 함께 표시
- 상세 특징표의 제목·행 이름·설명 모두 병기
- `검토 메모`가 화면·출력·HTML 문자열에 없음
- 컨설턴트 조작부는 한국어 유지
- 남성 화면에 여성 연예인·여성 메이크업 사례 없음
- 여성 연예인 이름은 공식 영문 표기

### 태블릿과 출력

- 세로 태블릿에서 두 언어와 이미지가 잘리지 않음
- 가로 태블릿에서 언어 쌍의 폭이 지나치게 좁아지지 않음
- 상세 특징표가 가로 스크롤 없이 읽힘
- 출력 화면에 두 언어가 모두 포함되고 페이지 경계에서 표가 잘리지 않음

### 기존 기능 회귀

- 문항별 최대 2개 선택
- 뒤로가기와 답변 복원
- ABCD 합산과 1·2위 강조
- PDF 순서의 12타입
- 컨설턴트의 자유로운 최종 타입 선택
- 여성·남성별 B그룹명
- 단일 HTML의 기존 해설 직접 링크

## 13. 구현 순서

1. 확정 설계를 구현 계획으로 분해
2. 중앙 콘텐츠 구조와 누락 검사를 먼저 작성
3. 기존 해설 데이터를 구조화된 콘텐츠로 이전
4. 전체 일본어·중국어 간체·중국어 번체 초안 작성
5. 체크리스트 확대 기능 제거
6. 남성 이미지 세트 생성·분리·연결
7. 연예인 공식 영문명 매핑
8. 태블릿·출력 화면 구현
9. 자동검사와 실제 화면 검수
10. 사용자에게 로컬 초안 전달
11. 문구·번역·남성 이미지 검수 후 한 번에 수정
12. 사용자 승인 후 별도 배포

## 14. 완료 조건

- 확정된 모든 기능이 단일 v17 HTML에서 동작
- 번역·남성 이미지·영문 이름 누락 없음
- `검토 메모`와 체크리스트 확대 기능 없음
- 전체 자동검사 통과
- 태블릿 세로·가로 및 출력 화면 확인
- 공개 링크는 사용자의 별도 배포 요청 전까지 변경하지 않음
