# 컨설턴트 진단 문항 안내 설계

## 목표

컨설턴트가 사진만으로 모호하게 판단하지 않도록, 진단 10문항마다 일관된 관찰 기준과 선택지별 보조 설명을 제공한다.

## 범위

- 진단 점수, A–D 분류, 최대 2개 선택 규칙은 변경하지 않는다.
- 컨설턴트 전용 진단 화면에만 한국어 안내를 표시한다.
- 문항별로 `guide`(판단 기준)와 `hint`(헷갈릴 때 확인할 포인트)를 추가한다.
- 각 선택지에는 한 줄의 `detail`을 추가한다.
- 기존에 서로 모순되거나 불명확했던 눈썹 D, 입 A 등의 문구를 수정한다.

## 화면 구성

문항 제목과 영문 부제 아래에 다음 순서로 표시한다.

1. 공통 안내: 정면·무표정 우선, 두 특징이 모두 분명할 때만 최대 2개 선택
2. 문항별 판단 기준
3. 선택지명과 한 줄 보조 설명
4. 헷갈릴 때 확인할 포인트

태블릿의 2×2 카드 구조와 이미지 영역은 유지한다. 설명은 카드 안의 이름 아래에 두어 추가 탭이나 팝업 없이 읽을 수 있게 한다.

## 검증

- 모든 문항에 판단 기준과 확인 포인트가 있어야 한다.
- 화면은 공통 안내, 문항별 안내, 선택지 설명을 렌더링해야 한다.
- 수정한 눈썹 D와 입 A 문구가 화면에 표시되어야 한다.
- 기존 진단 UI·빌드·레이아웃 테스트를 모두 통과해야 한다.
