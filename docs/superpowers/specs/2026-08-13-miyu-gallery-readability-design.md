# 미유 해설 갤러리·가독성 보강 설계

## 목표

태블릿 상담 화면에서 추천·회피·패션 이미지를 넓고 밀도 있게 보여주며, 한국어와 고객 언어를 빠르게 구분해 읽게 한다.

## 확정 설계

- PPT 사진 보드는 사진 수에 맞춰 2~4개의 균형 행으로 나누고, 마지막 줄의 빈 칸을 만들지 않는다.
- PPT 안의 작고 순백색인 자리표시 이미지는 사진 보드에서 제외한다.
- 평균 얼굴은 4:5 비율을 유지한다. 메이크업·헤어·패션 보드는 원래 비율을 유지하고, 세로 태블릿에서 최대 680px 폭을 사용한다.
- 세로 태블릿의 가이드 설명은 2열로, 좁은 휴대폰은 1열로 보인다.
- 고객용 한국어는 15~18px·650~700 굵기, 번역문은 12~15px·500~550 굵기와 보조색으로 보인다.

## 검증

- 834×1194 세로 태블릿에서 스타일 보드는 600px 이상, 평균 얼굴은 4:5 비율인지 검사한다.
- 가이드의 한국어가 번역문보다 크고 굵은지 검사한다.
- 10개 사진의 PPT 보드는 4·3·3행으로 분리되어 빈 칸 없이 배치되는지 검사한다.
- Full V1이 현재 소스에서 재생성한 결과와 일치하고 95MiB 미만인지 검사한다.
