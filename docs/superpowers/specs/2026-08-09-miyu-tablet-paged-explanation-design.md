# 미유 태블릿 페이지형 해설 설계

## 목적

매장 상담 중 불필요하게 긴 세로 스크롤을 줄이고, 고객이 현재 어떤 타입의 설명을 보고 있는지 즉시 알 수 있게 한다.

## 확정된 화면 흐름

1. 고객 정보·소개·브릿지·진단 문항·점수 결과는 834×1194 세로 태블릿에서 기본 조작 영역이 한 화면에 보이도록 압축한다.
2. 해설은 긴 한 페이지 대신 이전·다음으로 넘기는 섹션 페이지로 전환한다.
3. 해설 공통 상단은 `그룹명 · 세부타입명` 한 조합만 표시한다. 레거시 카테고리 제목·예시 인물 제목은 해설 페이지 안에서 반복 노출하지 않는다.
4. 해설 페이지 순서는 다음과 같다.
   - 결과 요약
   - 평균 얼굴 참고 이미지와 이목구비 핵심
   - 무드 설명
   - 메이크업(남성은 그루밍)
   - 헤어
   - 액세서리·패션
5. 한 섹션의 한국어·선택 언어·PPT 전문이 태블릿 가독성을 해칠 만큼 길면, 그 섹션만 `1/2`, `2/2`로 나눈다. 글자를 줄여 한 화면에 억지로 넣지 않는다.

## 이미지 기준

- 평균 얼굴은 여성·남성 각 12타입, 총 24장을 새 AI 참고 이미지로 교체한다.
- 각 이미지는 성인 동아시아인, 정면 또는 약한 정면 구도, 머리·이마·눈썹·눈·코·입·턱선이 모두 보이는 상반신 비율로 만든다.
- 실제 인물·연예인 닮은꼴·반쪽 얼굴·과도한 클로즈업·워터마크·텍스트는 사용하지 않는다.
- 화면은 `object-fit: contain`을 사용해 얼굴을 자르지 않는다.
- 고객 표기는 `평균 얼굴 참고 이미지`와 `이 타입의 이목구비 특징을 바탕으로 만든 AI 참고 이미지예요.`를 한국어와 선택 언어로 함께 표시한다.

## 내용 기준

- PPT의 12타입별 메이크업·그루밍, 헤어, 액세서리·의상 추천을 원문 기준표와 대조해 빠진 항목 없이 반영한다.
- 여성 메이크업 사진과 그룹별 헤어 사진은 PPT 자산을 계속 사용한다.
- 남성은 AI 평균 얼굴을 그루밍 참고 이미지로 사용하고, 헤어는 PPT 그룹별 자산을 사용한다.
- 예시 인물은 모든 화면에서 영문 `Name (Group)` 또는 `Name (Actor)` 또는 `Name (Solo Artist)` 형식으로 통일한다.

## 검증 기준

- 834×1194와 1194×834에서 진단 전·문항·결과 화면의 가로 넘침이 없다.
- 해설은 현재 페이지 하나만 보이고, 최종 선택 그룹·세부타입 제목이 한 조합으로 고정된다.
- 24개 AI 평균 얼굴은 모두 로드되고, 이미지 자연 크기가 있으며, 얼굴을 채우기 위한 `cover` 표기가 없다.
- 12타입·여성/남성·3개 선택 언어의 메이크업/그루밍·헤어·액세서리·패션 내용이 비어 있지 않다.
- 생성 단일 HTML은 외부 이미지 주소 없이 모든 새 이미지를 포함하고 95MiB 미만을 유지한다.
