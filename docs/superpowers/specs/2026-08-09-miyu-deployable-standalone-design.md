# 미유 v17 배포 가능 단일 파일 보완 설계

## 목표

고객이 진단을 마친 뒤 태블릿에서 성별·언어에 맞는 해설을 안정적으로 볼 수 있게 하고, GitHub Pages에 올릴 수 있는 단일 HTML을 만든다.

## 확정 범위

1. 결과 HTML을 95 MiB 이하로 제한한다. GitHub의 100 MiB 파일 제한보다 충분히 낮은 기준이다.
2. 로고는 PNG로 유지하고, 문항·타입의 사진형 이미지 80개는 JPEG로 최적화한다. 원본 PNG는 보관한다.
3. 생성 HTML은 여전히 외부 이미지 요청이 없는 단일 파일이다. 빌드는 자산의 실제 MIME 형식으로 `data:image/png` 또는 `data:image/jpeg` URI를 만든다.
4. 대분류 화면의 동적 연예인 목록도 기존 정적 카드와 같은 공식 영문 이름을 사용한다. 이미지 검색은 영문 이름으로 일치해야 하며 `?` 자리표시자가 생기면 빌드 또는 회귀 검사가 실패한다.
5. 남성 프로필에서는 아직 남성 버전이 없는 레거시 인덱스·대분류·무드북을 메뉴와 직접 URL에서 막고 진단 결과 화면으로 보낸다. 12타입 상세 해설은 계속 남성 버전으로 제공한다.
6. 현재 대용량 이력이 있는 `codex/miyu-full-bilingual-male` 브랜치는 백업으로 남긴다. 모든 보완 검증 뒤 `main`을 기반으로 한 새 배포용 브랜치에 작은 dist만 포함한 단일 스쿼시 커밋을 만든다.
7. 실제 iPad 또는 동급 기기에서 첫 로딩·문항 전환·세로/가로·OS 인쇄 미리보기를 확인하기 전에는 공개 배포하지 않는다.

## 구조

### 이미지 최적화

`scripts/optimize-standalone-assets.mjs`가 원본 `assets/diagnosis`의 문항·타입 PNG를 읽어, 동일한 논리 키를 가진 JPEG 파생 자산과 매니페스트를 만든다. 품질은 얼굴 윤곽과 텍스트가 깨지지 않는 범위에서 시각 비교로 확정하고, 95 MiB 제한을 넘으면 빌드가 실패한다.

`scripts/build-v17.mjs`는 논리 키(`questions/...`, `types/...`, `logo`)는 그대로 유지하고 매니페스트의 실제 파일과 MIME 형식만 참조한다. 따라서 진단 UI와 성별 선택 로직은 바꾸지 않는다.

### 동적 연예인 목록

빌드 시 v16의 `CAT_PERSONS` 데이터는 `celebrity-names.js`의 단일 공식 영문 매핑으로 변환한다. 렌더러가 쓰는 이름과 정적 카드의 이름이 같아져 이미지 연결과 표시 언어가 함께 맞는다. 누락된 매핑이나 이름·이미지 불일치는 빌드 전에 실패한다.

### 남성 세션 경계

유효한 남성 프로필이 있으면 상단 레거시 탐색을 숨기고 `#/index`, `#/macro/*`, `#/moodbook/*` 요청은 `#/diagnosis/result`로 되돌린다. `#/cat/<id>`의 12타입 상세 해설은 기존 성별별 이중언어 패널로 남는다. 프로필이 없거나 여성인 기존 레거시 경로는 유지한다.

### 배포용 이력

완성 후 새 브랜치는 `main`에서 시작한다. 기능 변경과 95 MiB 이하 dist를 한 커밋으로 넣어, 이전 106.8MB blob이 새 브랜치의 Git 이력에 포함되지 않게 한다. 기존 개발 브랜치는 삭제하거나 덮어쓰지 않는다.

## 검증

- JPEG 파생 자산 수·논리 키·MIME·원본 대비 치수를 검사한다.
- 저장 dist와 재생성 dist가 같은지, 95 MiB 이하인지, 81개 자산이 외부 경로 없이 내장됐는지 검사한다.
- 여성 `#/macro/*`에서 영문 연예인 이름과 실제 이미지가 함께 보이는지 검사한다.
- 남성 세션에서 레거시 메뉴와 `#/macro/*`, `#/moodbook/*`가 결과 화면으로 이동하고 여성 메이크업·연예인 화면이 나타나지 않는지 검사한다.
- 834×1194 및 1194×834 브라우저 검수와 출력 미디어 검수를 다시 실행한다.
- 실제 iPad 검수는 자동화 완료 뒤 사람이 확인하는 공개 배포 게이트다.

## 비범위

- 남성용 대분류·무드북·메이크업 콘텐츠를 새로 쓰지 않는다.
- 점수 계산, 12타입 매핑, v16 원본, 원본 PNG 자산은 바꾸지 않는다.
- 사용자 승인 전 GitHub Pages 배포 또는 push는 하지 않는다.
