# MIYU Full V1 파일명 전환 및 시작 화면 간소화 설계

## 목표

컨설턴트가 고객명과 컨설턴트명을 입력하지 않고 바로 진단을 시작하게 하고, 고객에게 전달되는 단일 HTML의 정식 이름을 `Full_V1`으로 전환한다.

## 시작 화면과 진단 정보

- 시작 화면에는 해설 언어, 성별, 진단일만 입력한다.
- 고객명·컨설턴트명 입력, 안내 문구 `10개의 항목을 차례로…`는 제거한다.
- 결과와 해설에서 빈 고객명·컨설턴트명이 보이지 않도록 관련 메타 표시도 제거한다.
- 이전 저장 기록은 이름 필드를 무시하고, 해설 언어·성별·진단일·답안이 유효하면 그대로 복원한다.
- 내부 저장 키와 진단 버전 값은 유지한다. 이미 진행 중인 탭의 진단 흐름을 끊지 않기 위해서다.

## 파일명과 링크

- 정식 단일 파일은 `dist/미유_무드진단_Full_V1.html`이다.
- 루트 `dist/index.html`은 정식 파일로 이동한다.
- 기존 `dist/미유_무드진단_12type_v17.html`은 정식 파일로 이동하는 호환 페이지로 바꾼다.
- 두 이동은 주소의 `#` 뒤 진단 단계도 그대로 보존한다.
- 내부 빌드 함수와 저장 키의 `v17` 이름은 호환성을 위해 그대로 둔다.

## 검증

- 시작 화면에 이름 입력과 기존 안내 문구가 없어야 한다.
- 세 항목만으로 진단을 시작하고 저장·복원할 수 있어야 한다.
- 새 정식 파일, 루트 주소, 기존 v17 직접 주소가 모두 같은 진단 화면을 열어야 한다.
- 기존 자동검사와 단일 파일 최신성 검사를 통과해야 한다.
