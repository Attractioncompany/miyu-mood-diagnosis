# MIYU PPT 세부 가이드 완전 반영 설계

## 목적

고객이 해설을 볼 때 기존의 짧은 권장 문단만 보던 불편을 해결한다. 컨설턴트는 PPT를 다시 찾아보지 않고도, 타입별로 어떤 피부 표현·색감·포인트를 설명해야 하는지와 피하면 좋은 방향을 바로 확인할 수 있어야 한다.

## 확정 범위

- 해설 첫 페이지의 병합 구조(평균 얼굴·이목구비·무드)는 유지한다.
- 여성 메이크업은 12개 세부 타입별로 PPT 내용을 구조화한다.
- 여성 헤어는 A/B/C/D 대분류별로 PPT 내용을 구조화한다.
- 남성은 타입별 그루밍과 대분류별 헤어를 PPT 기준으로 구조화한다.
- 모든 고객용 내용은 한국어와 선택 언어(일본어·중국어 간체·중국어 번체)를 함께 제공한다.
- 번역은 한국어 문장 구조를 그대로 옮기지 않고, 현지 고객이 이해하기 쉬운 뷰티 용어로 자연스럽게 쓴다.
- 설명 이해에 도움이 되는 AI 참고 이미지를 생성해 포함한다. 이미지가 없는 항목을 장식용 이미지로 채우지는 않는다.

## 화면 설계

해설은 기존 8페이지 구조를 유지하되, 스타일 가이드 4페이지를 아래처럼 바꾼다.

1. **추천 메이크업 / 그루밍**
   - 피부 표현, 색감, 전체 느낌, 살릴 포인트를 각각 분리한다.
   - 각 항목은 한국어와 선택 언어를 위아래로 병기한다.
   - 타입별 AI 참고 이미지는 얼굴 전체보다 핵심 부위(눈·립·피부 질감)가 읽히도록 구성한다.
2. **피하면 좋은 메이크업 / 그루밍**
   - ‘안 어울림’ 대신 인상을 흐릴 수 있는 요소라는 맥락을 유지한다.
   - PPT의 회피 요소를 짧은 목록으로 분리한다.
   - 추천 이미지 재사용 대신, 대비를 설명하는 AI 참고 이미지가 필요한 타입에만 넣는다.
3. **추천 헤어**
   - 대분류별 헤어의 질감·볼륨·실루엣을 요약하고, PPT에 나온 스타일명 목록을 모두 표시한다.
4. **피하면 좋은 헤어**
   - PPT 회피 스타일명을 목록으로 표시하고, 추천 방향과 혼동되지 않게 분리한다.

액세서리·패션 페이지는 이번 범위에서 유지한다.

## 데이터 구조

각 스타일 가이드는 단순 문단이 아니라 아래 형태를 사용한다.

```js
{
  skin: localized(...),
  color: localized(...),
  feeling: localized(...),
  focus: localized(...),
  recommendedItems: [localized(...), ...],
  avoidItems: [localized(...), ...],
  visual: 'reference/...'
}
```

- 여성 메이크업은 타입명 키의 12개 가이드다.
- 남성 그루밍은 타입명 키의 12개 가이드다.
- 헤어는 성별×대분류 키의 8개 가이드다.
- 단일 HTML 파일의 배포 한도(95 MiB)를 넘지 않도록 새 AI 이미지는 압축된 JPEG로 만들고, 빌드에서 전체 크기를 검증한다.

## 이미지 원칙

- 기존 PPT 메이크업 참고 사진은 계속 사용한다.
- 새 AI 이미지는 다음처럼 텍스트만으로 이해하기 어려운 경우에만 추가한다.
  - 메이크업의 핵심 포인트가 눈·입술·피부 중 특정 부위에 있는 경우
  - 추천과 회피 방향의 실루엣 대비가 핵심인 헤어인 경우
- 한 페이지에는 최대 한 장의 새 AI 참고 이미지만 둔다.
- 연예인과 닮은 얼굴, 실제 인물 사진, 과도한 보정은 사용하지 않는다.

## 검증 기준

- 12개 여성 타입 모두 `피부/색감/느낌/포인트` 네 항목과 추천·회피 요소가 존재한다.
- 12개 남성 타입 모두 타입별 그루밍 정보가 존재한다.
- 8개 성별×대분류 헤어 가이드 모두 추천·회피 스타일명이 존재한다.
- D그룹 3개 타입은 PPT 내용이 서로 바뀌지 않는다.
- 한국어·일본어·간체·번체 모두 각 항목이 비어 있지 않다.
- 세로 834×1194 및 가로 1194×834 태블릿에서 가로 넘침이 없고, 설명 페이지는 한 페이지 단위로 이동한다.
- 새 이미지 포함 후 Full V1 단일 파일이 95 MiB 미만이다.
