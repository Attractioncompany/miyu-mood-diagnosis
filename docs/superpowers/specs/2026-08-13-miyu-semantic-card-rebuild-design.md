# MIYU 해설 카드 의미 연결 재구성 설계

## 목적

해설의 추천·패션·헤어 카드는 고객에게 보이는 이미지와 설명이 반드시 같은 대상을 설명해야 한다. 현재처럼 PPT에서 이미지를 자동으로 골라 공통 문구를 붙이거나, 하나의 공통 문장을 여러 카드에 반복 적용하지 않는다.

이 설계는 여성과 남성 해설 모두에 적용한다. 여성 자료는 PPT에서 의미가 명확한 이미지부터 채택하고, 단일 스타일을 식별할 수 없는 PPT 콜라주와 남성 참고 이미지는 타입 특징에 맞춘 생성 이미지로 보완한다.

## 현재 오류와 원인

1. 데일리 코디 3장은 제목만 다르고 소재·디자인·액세서리·유의사항을 공통 데이터에서 반복해 모두 같은 내용이 된다.
2. 데일리 코디 이미지는 고정 틀 안에서 `object-fit: cover`로 렌더되어 인물의 머리와 상단이 잘린다.
3. 패션 레퍼런스는 이미지의 실제 내용과 상관없는 공통 캡션을 붙인다.
4. 헤어 레퍼런스는 PPT의 복수 스타일 콜라주를 자동 추출한 뒤 단일 스타일명으로 설명한다.

## 선택한 구조

### 카드 매니페스트

새 카드 데이터 모듈은 고객에게 보이는 카드 하나를 하나의 객체로 관리한다.

```js
{
  image: 'reference/female/hair/avoid/b/hime-cut.jpg',
  source: 'ppt' | 'generated',
  layout: 'portrait' | 'landscape' | 'natural',
  caption: { ko, ja, 'zh-CN', 'zh-TW' },
  cropPosition: 'center' | 'top'
}
```

카드의 문구는 이미지 배열의 순서로 자동 배분하지 않는다. 이미지와 문구는 같은 객체 안에 있어 다른 카드와 섞일 수 없다.

### 이미지 선정 원칙

- PPT 이미지가 하나의 헤어·메이크업·패션 특징을 분명히 보여 주면 해당 이미지를 그대로 채택한다.
- 여러 인물·여러 스타일·텍스트가 한 이미지에 섞여 단일 캡션을 붙일 수 없으면 고객 화면에 사용하지 않는다.
- 위 경우와 남성 참고 카드는 설명을 이해시키는 생성 이미지로 대체한다. 생성 이미지는 실존 인물이나 연예인을 모방하지 않고, 카드의 설명 대상만 선명하게 보여 준다.
- PPT를 쓴 카드에는 추출 슬라이드 정보를 내부 매니페스트에 남겨, 이후 내용 검수 시 출처를 확인할 수 있게 한다.

### 데일리 코디

데일리 코디는 성별·12세부타입·룩 번호별로 독립 데이터를 갖는다. 각 룩에는 다음 값이 모두 별도 문장으로 들어간다.

- 룩 이름과 이미지
- 소재
- 패턴·디자인·실루엣
- 액세서리의 크기·형태·색
- 조합 시 유의사항

여성은 12타입 × 3룩, 남성도 12타입 × 3룩을 제공한다. 이미지가 그룹 공통인 경우에는 타입 전용 이미지로 교체한다. 이렇게 해야 같은 이미지에 타입별로 다른 설명을 얹는 오류가 재발하지 않는다.

### 화면 표시

- 패션·헤어·메이크업·데일리 이미지에는 공통 세로 비율을 강제하지 않는다. 매니페스트의 `layout`을 기준으로 원본 비율을 유지한다.
- 인물을 보여 주는 데일리 코디는 이미지 전체를 보이게 하며, 고정 높이에서 머리나 상체를 자르지 않는다.
- 가로형 이미지도 회색 여백이 생기지 않도록 이미지 높이를 원본 비율에 맞춘다.
- 가로 갤러리는 태블릿에서 2~3장, PC에서 3장을 기준으로 보이게 하고, 나머지는 명확한 좌우 이동 버튼·스크롤바·스와이프로 접근 가능하게 한다.

## 구현 범위

1. 기존 자동 매핑 보조 함수와 공통 패션 캡션을 카드 매니페스트 조회로 교체한다.
2. PPT 자산 추출 스크립트는 카드별 출처를 보존하고, 단일 의미가 없는 자동 샘플링을 중단한다.
3. 부족한 여성·남성 참고 이미지를 생성하고, 프로젝트 자산으로 최적화해 포함한다.
4. 데일리 코디 데이터와 화면 렌더러가 카드별 고유 설명을 사용하도록 바꾼다.
5. CSS는 카드별 레이아웃 값을 읽어 전체 이미지가 보이는 비율로 렌더한다.
6. 빌드된 단일 HTML, 직접 해설 경로, 진단 결과 경로 모두 동일한 데이터로 렌더되는지 확인한다.

## 검증 기준

- 모든 타입·성별의 데일리 코디 3장은 네 설명 필드가 룩마다 고유하며, 동일 문장이 반복되지 않는다.
- 모든 고객 노출 카드에는 한국어·일본어·중국어 간체·중국어 번체 캡션이 있다.
- 모든 카드의 캡션은 해당 카드의 자산 매니페스트에 직접 연결돼 있다. 자동 순번·순환 캡션 매핑은 사용하지 않는다.
- 대표 여성 타입 A/B/C/D와 남성 타입 A/B/C/D의 메이크업·헤어·패션·데일리 화면을 데스크톱과 834×1194 태블릿 크기에서 확인한다.
- 이미지가 강제 `cover` 처리로 잘리지 않고, 가로형 PPT 이미지에 불필요한 회색 여백이 생기지 않는다.
- 기존 기능(진단 결과 해설, 해설 바로보기, 다음·이전, 다른 타입 해설 보기, 다국어 병기)이 회귀하지 않는다.
- 전체 자동 검사, PPT 자산 검사, 단일 HTML 빌드 최신성·크기 제한을 통과한 뒤에만 배포한다.

## 제외 범위

- 진단 문항·점수 계산·12타입 판정 규칙은 변경하지 않는다.
- 해설의 이목구비와 메이크업/헤어 원문 자체를 이번 작업에서 새 이론으로 바꾸지 않는다. 이미지와 문구의 연결 및 표현 정확성만 바로잡는다.
