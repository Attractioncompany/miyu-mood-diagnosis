# 미유 다국어·성별 해설 설계

- 작성일: 2026-07-30
- 대상: `미유_무드진단_12type_v17.html`
- 상태: 사용자 승인 설계

## 1. 해결할 고객 불편

현재 해설은 한국어와 여성 스타일링을 기준으로 작성되어 있다. 일본어·중국어권 고객은 컨설턴트의 통역에 전적으로 의존해야 하고, 남성 고객은 자신의 스타일링에 바로 적용하기 어려운 여성 메이크업 해설을 보게 된다.

이번 변경은 다음 문제를 해결한다.

1. 컨설턴트와 외국인 고객이 같은 화면에서 한국어와 고객 언어를 함께 본다.
2. 얼굴 특징과 타입 판정은 유지하면서 성별에 맞는 스타일링 해설을 제공한다.
3. 진단 전에 입력하는 정보는 실제 해설과 기록에 필요한 항목만 남긴다.

## 2. 변경 범위

### 포함

- 최초 입력 화면에서 퍼스널컬러 항목 제거
- 고객명, 컨설턴트명, 해설 언어, 성별, 진단일 입력
- 최종 해설에 한국어와 선택 언어 동시 표시
- 여성·남성별 스타일링 해설 분리
- 남성 화면에서 B그룹을 `Boyish · 보이시`로 표시
- 태블릿 세로 화면 우선의 다국어 해설 배치
- 입력값 누락과 콘텐츠 누락에 대한 안전한 처리

### 제외

- 진단 문항 자체의 번역
- ABCD 점수표와 컨설턴트용 12타입 선택 화면의 번역
- 진단 로직, ABCD 가중치, 12타입 매핑 변경
- 앞서 제안한 문항 사진·답변 문구 개선
- 신규 남성 연예인 사진 수집 및 추가
- 서버 저장, 고객 데이터베이스, 로그인 기능

## 3. 전체 사용자 흐름

1. 고객 정보 입력
2. 진단 문항을 순서대로 진행
3. ABCD 점수 합산표 확인
4. PDF 순서대로 12타입 전체 확인
5. 1위·2위 타입 강조 확인
6. 컨설턴트가 최종 타입 선택
7. 선택한 성별과 언어에 맞는 최종 해설 표시

기존 진단 규칙은 유지한다.

- 문항마다 최대 2개 선택
- 이전 문항으로 이동 가능
- 점수와 관계없이 컨설턴트가 12타입 중 하나를 최종 선택 가능

## 4. 최초 입력 화면

| 항목 | 입력 방식 | 필수 여부 | 동작 |
|---|---|---:|---|
| 고객명 | 텍스트 입력 | 필수 | 결과 화면에 표시 |
| 컨설턴트명 | 텍스트 입력 | 필수 | 결과 화면에 표시 |
| 해설 언어 | 목록 선택 | 필수 | 다국어 해설 결정 |
| 성별 | 여성 / 남성 | 필수 | 스타일링 해설 결정 |
| 진단일 | 날짜 입력 | 필수 | 오늘 날짜 자동 입력, 수정 가능 |

해설 언어의 화면 표기는 다음과 같이 고정한다.

- 일본어
- 중국어 간체(중국)
- 중국어 번체(홍콩·대만)

잘못된 언어로 진단을 시작하는 일을 막기 위해 해설 언어와 성별에는 임의 기본값을 넣지 않는다. 모든 필수 항목을 입력하거나 선택해야 다음 단계로 이동할 수 있다.

## 5. 다국어 표시 원칙

### 번역 범위

번역은 최종 타입 해설에만 적용한다.

- 타입의 전체 인상
- 얼굴 특징 설명
- 타입의 장점
- 헤어 방향
- 메이크업 또는 그루밍 방향
- 패션 방향
- 피하면 좋은 방향
- 해설 안에서 사용하는 짧은 안내 문구

진단 문항, 답변, ABCD 점수표, 진행표, 컨설턴트용 타입 선택 UI는 한국어로 유지한다.

### 표시 방식

- 한국어를 항상 먼저 표시한다.
- 각 한국어 항목 바로 아래 또는 옆에 선택 언어를 표시한다.
- 언어를 탭으로 숨기지 않는다.
- 타입명과 코드는 기존 한국어·영문 표기를 유지한다.
- 고객명, 컨설턴트명, 진단일은 번역하지 않는다.
- 번역은 브라우저 자동번역이 아니라 사전에 검수한 고정 문구를 사용한다.

### 태블릿 배치

- 세로 화면: 한 카드 안에서 `한국어 → 구분선 → 선택 언어` 순서로 배치
- 가로 화면: 폭이 충분하면 같은 카드 안에서 한국어와 선택 언어를 좌우 2열로 배치
- 두 언어는 같은 해설 항목 안에 묶어 이미지와 설명의 연결이 끊기지 않게 한다.
- 글자 크기와 버튼 높이는 기존 태블릿 터치 기준을 유지한다.

## 6. 여성·남성 해설 구조

타입 정의와 얼굴 특징은 공통으로 사용한다. 성별은 판정 결과를 바꾸지 않고 스타일링 해설만 바꾼다.

### 공통 콘텐츠

- 타입 코드와 이름
- 얼굴 특징
- 전체적으로 보이는 인상
- 해당 타입이 가진 장점

### 여성 콘텐츠

- 헤어
- 메이크업
- 패션
- 피하면 좋은 방향

### 남성 콘텐츠

- 헤어
- 그루밍
- 패션
- 피하면 좋은 방향

그루밍은 피부 표현, 눈썹, 수염 정돈처럼 남성 고객이 바로 적용할 수 있는 범위로 작성한다. 남성성을 강요하거나 여성적인 요소를 부정하는 문장은 사용하지 않는다.

남성 화면에서는 기존 여성 대표 인물의 프로필·사진·여성 스타일링 사례를 숨긴다. 남성 인물 자료가 준비되지 않은 상태에서 여성 인물이나 여성 메이크업 설명을 대체 콘텐츠로 사용하지 않는다. 공통 얼굴 특징은 우선 텍스트로 제공한다.

## 7. 성별별 그룹명

| 그룹 | 여성 화면 | 남성 화면 |
|---|---|---|
| A | `Blossom · 블로썸` | `Blossom · 블로썸` |
| B | `Feminine · 페미닌` | `Boyish · 보이시` |
| C | `Mood · 무드` | `Mood · 무드` |
| D | `Modern · 모던` | `Modern · 모던` |

그룹명 변경은 화면 표시 전용이다. 내부 그룹 코드 B, 점수, 타입 매핑은 변경하지 않는다.

남성 B그룹 세부 표현은 다음 기준을 사용한다.

- B-1 로맨틱: 감성적인 보이시
- B-2 소프트: 차분한 보이시
- B-3 엘레강스: 단정하고 지적인 보이시

## 8. 남성 12타입 한국어 초안

| 타입 | 전체 인상과 스타일링 방향 |
|---|---|
| A-1 판타지 | 신비롭고 감각적인 인상. 가벼운 헤어와 간결한 스타일에 독특한 포인트가 잘 맞는다. |
| A-2 프루티 | 밝고 생기 있는 인상. 자연스러운 볼륨과 선명한 색상 포인트가 장점을 살린다. |
| A-3 소다 | 맑고 친근한 인상. 가벼운 앞머리와 산뜻한 캐주얼 스타일이 잘 어울린다. |
| B-1 로맨틱 | 감성적인 보이시. 부드러운 헤어와 니트·셔츠처럼 편안한 소재가 잘 맞는다. |
| B-2 소프트 | 차분한 보이시. 과하지 않은 볼륨과 정돈된 스타일이 안정감을 높인다. |
| B-3 엘레강스 | 단정하고 지적인 보이시. 깔끔한 가르마와 재킷·코트가 잘 어울린다. |
| C-1 빈티지 | 자연스럽고 개성 있는 인상. 결이 살아 있는 헤어와 데님·스웨이드 같은 소재가 잘 맞는다. |
| C-2 세련 | 도시적이고 균형 잡힌 인상. 정돈된 헤어와 모노톤 스타일이 세련미를 높인다. |
| C-3 딥시크 | 깊고 강렬한 인상. 어두운 색과 절제된 스타일링이 분위기를 또렷하게 한다. |
| D-1 카리스마 | 골격이 선명하고 힘 있는 인상. 이마를 드러낸 헤어와 구조적인 옷이 잘 맞는다. |
| D-2 클리어 | 정갈하고 깨끗한 인상. 군더더기 없는 헤어와 흰색·네이비·회색이 잘 어울린다. |
| D-3 샤프 | 날렵하고 긴장감 있는 인상. 선이 또렷한 헤어와 각이 잡힌 옷이 장점을 살린다. |

이 표는 상세 해설 제작의 기준이다. 실제 고객 화면에서는 모든 문장을 친근한 `~해요` 말투로 작성한다.

## 9. 데이터와 화면 동작

최초 입력값은 현재 진단 세션 안에서만 유지한다.

- `customerName`: 고객명
- `consultantName`: 컨설턴트명
- `explanationLanguage`: `ja`, `zh-CN`, `zh-TW` 중 하나
- `gender`: `female`, `male` 중 하나
- `diagnosisDate`: `YYYY-MM-DD`

최종 타입이 선택되면 다음 순서로 해설을 결정한다.

1. 타입 코드로 공통 얼굴 특징과 전체 인상을 불러온다.
2. 성별로 여성 또는 남성 스타일링 콘텐츠를 불러온다.
3. 해설 언어로 해당 번역문을 불러온다.
4. 한국어와 번역문을 같은 섹션에 함께 표시한다.

진단을 다시 시작하면 기존 고객 정보와 답변을 초기화한다. 브라우저를 새로고침한 뒤에도 개인정보가 남지 않도록 고객 정보를 영구 저장하지 않는다.

## 10. 예외 처리

- 필수 입력값 누락: 해당 항목 아래에 짧은 오류 문구를 표시하고 다음 단계 이동을 막는다.
- 지원하지 않는 언어값: 한국어 해설만 표시하고 화면이 멈추지 않게 한다.
- 특정 번역문 누락: 해당 한국어 원문을 표시하고 누락된 번역 영역에 `번역 준비 중`을 표시한다.
- 남성 상세 해설 누락: 여성 메이크업 문구로 대신하지 않고 공통 해설만 표시한다.
- 잘못된 날짜: 오늘 날짜로 자동 복구한다.

## 11. 검증 기준

### 입력 화면

- 퍼스널컬러 입력란이 보이지 않는다.
- 다섯 가지 입력 항목이 모두 동작한다.
- 진단일에 오늘 날짜가 자동으로 들어가며 수정할 수 있다.
- 필수값이 빠지면 진단을 시작할 수 없다.

### 기존 진단 회귀 검증

- 문항별 최대 2개 선택 제한이 유지된다.
- 이전·다음 이동과 답변 복원이 정상 동작한다.
- ABCD 점수 합산이 기존과 동일하다.
- 1위·2위 강조가 유지된다.
- PDF 순서대로 12타입이 모두 표시된다.
- 컨설턴트가 점수와 관계없이 최종 타입을 선택할 수 있다.

### 다국어·성별 해설

- 세 언어 각각에서 한국어와 선택 언어가 함께 보인다.
- 여성 선택 시 기존 여성 해설이 표시된다.
- 남성 선택 시 남성 해설이 표시되고 여성 메이크업 문구가 노출되지 않는다.
- 남성 B그룹이 `Boyish · 보이시`로 표시된다.
- 여성 B그룹은 `Feminine · 페미닌`을 유지한다.
- 번역이나 성별별 콘텐츠가 누락돼도 빈 화면이나 오류가 발생하지 않는다.

### 태블릿

- 세로 화면에서 언어 쌍과 이미지가 잘리지 않는다.
- 가로 화면에서 두 언어가 읽기 쉬운 폭으로 배치된다.
- 터치 버튼과 입력칸이 기존 태블릿 기준보다 작아지지 않는다.

## 12. 후속 작업 순서

1. 남성 12타입 상세 한국어 해설 작성 및 검수
2. 여성·남성 한국어 원문 확정
3. 일본어, 중국어 간체, 중국어 번체 번역 및 검수
4. 입력 화면과 해설 전환 기능 구현
5. 다국어 태블릿 화면 구현
6. 기존 진단 기능과 신규 해설 기능 통합 검증
7. 문항 사진·답변 문구 개선을 별도 작업으로 진행

신규 남성 인물 사진은 공개 배포 시 저작권 위험이 있으므로 이번 구현에는 포함하지 않는다. 남성 해설은 공통 얼굴 특징 텍스트와 남성 스타일링 문구를 우선 사용한다.
