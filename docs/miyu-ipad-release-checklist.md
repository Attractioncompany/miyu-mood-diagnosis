# 미유 무드진단 · 샵 내부 상담용 iPad 확인표

아래 항목은 실제 iPad에서 한 번씩 확인한 뒤 체크합니다. 이 문서는 개발 검증을 대신하지 않으며, 매장 사용 환경에서 화면과 조작감을 마지막으로 확인하기 위한 목록입니다.

- [ ] 세로 모드에서 고객 정보 입력 → 소개 1·2·3 → 시작 안내 → 진단 1번까지 진행했을 때 버튼·글자·사진이 잘리지 않는다.
- [ ] 소개 2페이지에서 PPT 기준 4개 무드 그룹의 얼굴 사진과 이름이 모두 보인다.
- [ ] 시작 안내에 ‘컨설턴트가 진단을 진행하고, 이후 결과와 어울리는 스타일을 설명한다’는 뜻이 한국어와 고객 언어로 함께 보인다.
- [ ] 세로 모드에서 여성 고객·일본어 해설을 열었을 때, 5개 해설 순서가 한국어와 일본어로 함께 보이고 예시 사진이 잘리지 않는다.
- [ ] 세로 모드에서 남성 고객·중국어 번체 해설을 열었을 때, 5개 해설 순서가 한국어와 중국어 번체로 함께 보이고 여성 전용 메뉴가 보이지 않는다.
- [ ] 해설을 열면 평균 얼굴 참고 이미지가 이목구비 특징보다 먼저 나오며, 남성 경로에는 AI 참고 이미지라는 표기가 보인다.
- [ ] 메이크업(남성은 그루밍)과 헤어 설명에 각각 참고 사진과 ‘잘 어울리는 방향’ 설명이 보인다.
- [ ] 가로 모드로 돌린 뒤 점수 결과와 해설을 열었을 때 가로 스크롤이나 겹치는 버튼이 없다.
- [ ] 진단 중 이전·다음 버튼과 마지막 타입 선택 버튼을 손가락으로 누르기 편하다.
- [ ] 인쇄 또는 공유 버튼을 눌렀을 때 앱이 멈추지 않고, 정상적인 시스템 창으로 이어진다.
- [ ] 인터넷을 끈 뒤 이미 한 번 연 페이지에서 로고와 진단·해설 이미지가 정상 표시된다.
